# 世界杯足球比分预测 Skill

## 适用场景

- 用户需要预测世界杯小组赛、淘汰赛阶段的比赛结果
- 用户给出了多场对阵球队名称，希望批量输出比分预测
- 用户希望获得基于FIFA排名、历史战绩、球员状态的分层概率分析
- 用户需要中文Markdown格式的比分预测报告

## 工作要求

1. 必须先搜索双方球队的最新FIFA世界排名
2. 必须搜索双方球队的历史直接交锋记录
3. 必须搜索双方球队核心球员伤病、停赛信息
4. 必须搜索双方球队最近世界杯正式比赛状态和士气
5. 必须严格遵循分层预测输出格式
6. 每场对阵必须输出明确的比分预测（建议一个比分，不确定时可输出两个比分）

## 分析框架

### 一、基础参考研判物料（固定权重参考）

- 各国国家队传统硬实力、世界杯历史战绩、大赛声誉、球星阵容底蕴
- 洲际足球层级基准：欧洲 > 南美 > 非洲/中北美及加勒比 > 亚洲

### 二、核心变量维度（优先参考）

必须全部纳入以下维度综合加权判断：

1. FIFA官方最新国家队世界排名
2. 两队历史直接交锋对战记录、胜负平局规律
3. 双方核心主力球员伤病、红黄牌停赛名单
4. 本场赛事主客场、中立场地、地理气候场地影响
5. 两队最近世界杯正式比赛竞技状态、近期士气、攻防数据

## 预测风格定义

严格输出差异化预测思路，每套标注：

1. **风格定义**：保守型/平衡型/进取型等
2. **胜负平倾向**：明确主胜/客胜/平局倾向
3. **对应概率区间**：给出概率百分比区间
4. **核心逻辑依据**：列出支撑该预测的关键因素
5. **预测比分**：输出明确比分（建议一个，不确定时可输出两个）

## 预测原则

- 完全依托纸面硬实力、排名、历史战绩，优先强队不败
- 极少考虑冷门，容错极低
- 兼顾实力与客观变数（伤病、停赛、场地、士气）
- 每场对阵必须给出明确比分，不使用模糊表述

## 输出前自检

- 是否包含所有核心变量分析
- 是否给出了明确的胜负平倾向
- 是否给出了概率区间
- 是否输出了明确比分
- 是否使用中文Markdown
- 是否对多场对阵逐一分析
