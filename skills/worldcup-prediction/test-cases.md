# 世界杯比分预测 Skill 测试用例

## 测试目标

验证 `worldcup-prediction` skill 能否正确识别和调用，并输出符合要求的比分预测结果。

## 测试用例列表

### 测试用例1：预置场景测试

**目的**：验证skill能被正确识别和触发

**输入**：
```bash
UV_CACHE_DIR=/tmp/uv-cache uv run python main.py run --scenario worldcup-prediction
```

**预期输出**：
- 成功触发 `worldcup-prediction` skill
- 输出包含3场对阵的预测（巴西 vs 阿根廷、法国 vs 德国、英格兰 vs 西班牙）
- 每场对阵包含完整的分析结构（基础实力对比、核心变量分析、预测结论）
- 每场对阵给出明确的预测比分
- 输出格式符合template.md定义

**验证要点**：
1. 是否包含基础实力对比
2. 是否包含5个核心变量分析
3. 是否给出胜负平倾向
4. 是否给出概率区间
5. 是否输出明确比分
6. 是否使用中文Markdown

---

### 测试用例2：单场对阵预测

**目的**：验证skill能处理单场对阵预测

**输入**：
```bash
curl -X POST http://127.0.0.1:8000/api/v1/validate-skill \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4.1-mini",
    "prompt": "请预测世界杯比赛比分：巴西 vs 阿根廷"
  }'
```

**预期输出**：
- 输出包含完整的单场对阵分析
- 给出明确的预测比分（如 2-1 或 1-1）
- 包含胜负平倾向和概率区间
- 输出结构完整

**验证要点**：
1. 是否只包含一场对阵分析
2. 是否给出明确比分
3. 分析内容是否完整

---

### 测试用例4：跨洲际对阵预测

**目的**：验证skill能正确处理洲际层级差异

**输入**：
```bash
curl -X POST http://127.0.0.1:8000/api/v1/validate-skill \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4.1-mini",
    "prompt": "请预测世界杯对阵比分：巴西（南美） vs 日本（亚洲）、德国（欧洲） vs 墨西哥（中北美）"
  }'
```

**预期输出**：
- 正确识别洲际层级差异
- 分析中体现洲际实力差距
- 预测比分反映实力差距（如巴西 vs 日本预测比分应为明显差距）
- 概率区间反映强弱对比

**验证要点**：
1. 是否在基础实力对比中提到洲际层级
2. 是否在核心依据中体现洲际差异
3. 预测比分是否反映实力差距（如巴西胜日本比分可能为 3-0 或 4-1）

### 测试用例5：强队对决预测

- 正确识别双方都是顶级强队
- 分析中体现实力接近
- 预测比分反映均势（如 1-1、2-1、1-2 等接近比分）
- 概率区间相对平衡（如胜负概率接近）

**验证要点**：
1. 是否在基础实力对比中体现双方都是强队

3. 概率区间是否相对平衡
