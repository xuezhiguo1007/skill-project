# 世界杯比分预测 Skill 使用文档

## Skill简介

`worldcup-prediction` skill 是一个基于DeepAgents风格的足球比分预测技能，专门用于世界杯比赛比分预测。

## 核心特性

- **分层概率分析**：基于FIFA排名、历史战绩、球员状态等多维度变量进行综合分析
- **批量预测支持**：可以一次性预测多场对阵
- **明确比分输出**：每场对阵给出明确的预测比分（建议一个，不确定时可输出两个）
- **概率区间标注**：给出胜负平倾向和对应概率区间

## 分析框架

### 一、基础参考研判物料（固定权重）

- 各国国家队传统硬实力、世界杯历史战绩、大赛声誉、球星阵容底蕴
- 洞际足球层级基准：欧洲 > 南美 > 非洲/中北美及加勒比 > 亚洲

### 二、核心变量维度（优先参考）

分析时全部纳入以下维度综合加权：

1. FIFA官方最新国家队世界排名
2. 两队历史直接交锋对战记录、胜负平局规律
3. 双方核心主力球员伤病、红黄牌停赛名单
4. 本场赛事主客场、中立场地、地理气候场地影响
5. 两队最近世界杯正式比赛竞技状态、近期士气、攻防数据

## 预测风格定义

Skill会输出差异化预测思路，每套标注：

1. **风格定义**：保守型/平衡型/进取型等
2. **胜负平倾向**：明确主胜/客胜/平局倾向
3. **对应概率区间**：给出概率百分比区间
4. **核心逻辑依据**：列出支撑该预测的关键因素
5. **预测比分**：输出明确比分（建议一个，不确定时可输出两个）

## 预测原则

- 完全依托纸面硬实力、排名、历史战绩，优先强队不败
- 极少考虑冷门，容错极低
- 兼顾实力与客观变数（伤病、停赛、场地、士气）
- 每场对阵必须给出明确比分，不使用模糊表述

## 适用场景

- 世界杯小组赛比分预测
- 世界杯淘汰赛比分预测
- 多场对阵批量预测
- 基于数据分析的胜负概率研究

## 注意事项

1. 预测结果仅供参考，实际比赛结果可能受临场变数影响
2. Skill会主动搜索最新数据（FIFA排名、球员状态等）
3. 预测基于历史数据和统计分析，无法完全预测未来
4. 建议结合实际情况和个人判断使用预测结果
